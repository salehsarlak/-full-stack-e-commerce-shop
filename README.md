## 🌟 About The Project

**Bazaroon** is a complete full-stack e-commerce solution designed with a clean architecture and a beautiful Persian (RTL) user interface.  
It includes everything you need to run a real online store: product catalog, shopping cart, user accounts, and a powerful admin panel.

> Built from scratch using pure PHP and MySQL — no heavy frameworks, just clean and understandable code.

## 🚀 Getting Started

### Prerequisites

- PHP 7.4+ (recommended 8.x)
- MySQL / MariaDB
- Apache / Nginx (or XAMPP / Laragon / WAMP)

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/salehsarlak/-full-stack-e-commerce-shop.git
cd -full-stack-e-commerce-shop
```

2. **Create the database**

- Create a database named `dbpanel`
- Import your SQL dump (or create the required tables)

3. **Configure the database connection**

Open `config/db.php` and update the credentials if needed:

```php
$servername = "localhost";
$username   = "root";
$password   = "";
$dbname     = "dbpanel";
```

4. **Run the project**

Place the project in your web server root (e.g. `htdocs` or `www`) and open:

```
http://localhost/-full-stack-e-commerce-shop/
```
